# 🎵 XiaoMusic Web Theme for IPhone

> 基于 **XiaoMusic** 的一个纯前端 Web 主题  
> 专为 **iPhone / iOS Safari** 优化  
> 单文件 `index.html` 即可部署

---

## 📱 项目简介

这是一个为 XiaoMusic 打造的移动端 Web 播放主题，重点解决：

- iPhone Safari 播放兼容
    
- 锁屏播放控制
    
- 灵动岛显示
    
- 耳机线控操作
    
- 媒体中心控制
    
- 封面 & 歌词自动刮削展示
    

完全单 HTML 文件，无依赖构建工具。

---

## ✨ 核心特性

### 🍎 iPhone 完整兼容

- ✅ iOS Safari 播放稳定
    
- ✅ 锁屏封面与歌曲信息正常显示
    
- ✅ 灵动岛实时显示播放状态
    
- ✅ 耳机线控支持（上一曲 / 下一曲 / 暂停）
    
- ✅ 支持 MediaSession API
    
- ✅ 支持拖动进度（本机模式）

## 🔌 后端接口依赖

该主题基于 XiaoMusic 提供的接口运行：

/musiclist  
/musicinfo  
/getsetting  
/device_list  
/playingmusic  
/setvolume  
/getvolume  
/cmd  
/proxy/music

支持新版 `/proxy/music`，自动探测兼容旧版 `/proxy`。

## 📦 部署方式

只需要一个文件：

index.html

部署到：

- XiaoMusic Web 目录
    
- Nginx / Apache
    
- 或任何支持静态文件的服务器
    

无需构建，无需 Node。

---

## 🖥 桌面端适配

当屏幕宽度 ≥ 600px 时：

- 自动限制宽度为 480px
    
- 居中显示
    
- 添加投影效果
    
- 模拟手机使用体验
    

---

## 🎛 播放模式说明

|模式|说明|
|---|---|
|单曲循环|当前歌曲循环|
|列表循环|顺序播放|
|随机播放|随机切歌|

本机模式使用 LocalStorage 保存状态  
远程模式读取设备播放模式

---

## 🔊 音量逻辑

- 本机：保存到 LocalStorage
    
- 远程：调用 `/setvolume`
    
- iOS 本机播放禁用系统音量控制时自动降级
